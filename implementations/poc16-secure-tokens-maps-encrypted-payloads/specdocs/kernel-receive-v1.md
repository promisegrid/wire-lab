# kernel_receive_v1

`kernel_receive_v1` is retained as historical/specimen evidence from the earlier
POC16 app/kernel registration shape. Active POC16 runtime traffic now uses
`kernel_transport_v1` between the parser role and the transport kernel.

This pCID is not a remote procedure call surface and does not authorize other
agents. It should not appear in normal active message artifacts after the
parser-role correction. Source: `DI-gazin`.
