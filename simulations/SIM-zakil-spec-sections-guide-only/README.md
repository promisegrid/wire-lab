# SIM-zakil-spec-sections-guide-only

This simulation turns the guide-only prose alternative from
`SIM-ranib-spec-requirement-sections` into a concrete candidate specimen. It
tests whether the development guide should own explanatory prose while protocol
specs stay minimal and cite the guide. Source: `DI-fibuv`.

## Design Under Test

Protocol specs remain small normative documents. Promise vocabulary, 100-year
pressure, and layperson mental models live in guide prose, with specs carrying
only citations or short hooks.

## Boundaries

This simulation does not rewrite the development guide. It tests whether moving
explanation out of specs improves durability or separates implementers from the
exact promises they need to follow.
