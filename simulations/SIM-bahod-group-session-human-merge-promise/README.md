# SIM-bahod-group-session-human-merge-promise

This simulation turns the human merge-promise alternative from
`SIM-bohof-group-session-freeze-promise` into a concrete candidate specimen. It
tests whether Steve can make a plain-English `merge-group-transport-spec`
promise that points at exact artifacts and is precise enough for early freeze
work. Source: `DI-fibuv`.

## Design Under Test

The freeze action is a human-authored promise naming exact paths, CIDs, scope,
and unresolved questions. The promise is treated as evidence until stronger
signed-promise tooling exists.

## Boundaries

This simulation does not sign or execute a merge. It tests whether plain-English
promise wording can be durable enough for early specimen governance.
