# SIM-mipum-grid-envelope-signed-body-envelope-ucan-like: UCAN-like signed-body envelope probe

This simulation is a standalone grid-envelope specimen. It keeps the universal
outer shape minimal as `grid([pcid, payload])`, but makes the payload contract
explicitly separate a signed body from its proof material in one payload
envelope. Source: `DI-nohir`.

The local draft spec is
`protocols/grid-envelope.d/specs/grid-envelope-draft.md`.

Primary comparison targets: `SIM-riliz` and `SIM-pamap`.
