# SIM-fitin-gordian-payload-wrapper: Gordian payload/wrapper probe

This simulation is a standalone grid-envelope specimen. It keeps the universal
outer grid minimal and moves Gordian-style subject/assertion/proof structure
into a pCID-owned payload/wrapper family instead of treating Gordian semantics
as universal envelope doctrine. Source: `DI-nohir`.

The local draft spec is
`protocols/grid-envelope.d/specs/grid-envelope-draft.md`.

Primary comparison targets: `SIM-maraz` and `SIM-natim`.
